LOGIN PAGE

A simple and responsive login page built using HTML and CSS. This project features a clean user interface with email and password fields, a remember me checkbox, a forgot password link, and a sign-in buttom.

⭐ FEATURES
- Clean and modern user interface
- Email and password input fields
- Remember me checkbox
- Forgot password link
- Sign-up button with hover effects
- Responsive layout for different screen sizes

🛠️ Technologies Used
- HTML5
- CSS

🌐 Live Demo
Link to live demo: https://radhaanu28.github.io/login-page/

📚 What I Learned
- Structuring a webpage with HTML
- Styling forms and input fields with CSS
- Using hover and focus effects
- Creating a centered login card
- Organizing HTML and CSS into separate files

⚠️ Note
This is a frontend practice project. The login form is for demonstration purposes only and does not provide real authentication or store user credentials.
